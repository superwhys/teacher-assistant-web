# 教师助手（Teacher Assistant）

一个面向课堂场景的教师工作台，支持账号登录、班级与学期管理、学生管理、积分管理、积分商城、课堂工具箱、锁屏与反馈等能力。项目针对教室触控大屏做了操作区与信息布局优化，同时兼顾电脑端和手机端的响应式使用体验。

## 项目定位

本项目主要服务于日常教学管理场景，适合在教室大屏、教师电脑和手机浏览器中使用。当前实现重点集中在以下几类场景：

- 班级名册维护
- 学生分组与快速筛选
- 课堂积分加减与排行榜展示
- 积分记录检索、撤回、导出
- 积分商城兑换
- 课堂工具箱（计时器、点名器、抽奖器）
- 账号登录、试用提示、锁屏防误触、意见反馈

## 当前已实现功能

### 1. 账号与登录

- 支持登录、注册、忘记密码、邮箱验证码
- 支持通过 URL `token` 自动登录
- 支持登录过期检测与跳转登录页
- 支持试用账号状态展示与试用到期提示
- 支持读取用户资料并展示头像、邮箱、用户信息

### 2. 班级与学期管理

- 支持新建班级、编辑班级、删除班级
- 支持在设置页修改当前班级名称
- 支持切换当前班级
- 支持加载并切换当前班级下的学期
- 支持开启新学期
- 开启新学期时可选择是否清空积分
- 旧学期会进入归档状态，部分操作只读

### 3. 学生管理

- 支持单个添加学生
- 支持批量添加学生
- 支持 Excel 导入学生名单
- 支持编辑学生姓名、性别
- 支持删除学生
- 删除学生时会同步处理分组关联
- 支持卡片/列表等不同展示方式与排序方式

### 4. 学生分组

- 支持创建分组、编辑分组、删除分组
- 支持调整分组成员
- 支持按分组筛选学生
- 支持 Excel 导入分组数据

### 5. 积分管理

- 支持查看学生总积分与可用积分
- 支持单人、多人、全班加分或扣分
- 支持积分规则组与积分项管理
- 支持积分项 Excel 导入
- 支持积分 Excel 导入
- 支持排行榜展示
- 支持总榜和单项榜切换
- 支持按时间范围查看排行榜
- 支持最近一次操作撤回

### 6. 积分记录

- 支持查看积分历史记录
- 支持按姓名、分组、类型等条件筛选
- 支持撤回普通积分记录
- 商城兑换记录会显示在积分历史中，但不能在这里直接撤回
- 当前后端暂不支持“清空积分记录”

### 7. 积分商城

- 支持商品新增、编辑、删除
- 支持商品 Excel 导入
- 支持学生使用可用积分兑换商品
- 支持兑换记录分页查看
- 支持撤销兑换记录
- 兑换时会校验库存与学生可用积分

### 8. 工具箱

- 计时器：课堂倒计时展示
- 点名器：随机抽取学生
- 抽奖器：支持自定义奖品，也支持从商城导入
- 工具箱首页已预留“更多工具”入口位，表示后续仍会继续扩展

### 9. 设置与辅助能力

- 展示当前登录用户信息
- 支持修改当前班级名称
- 支持设置、修改、清除锁屏密码
- 支持立即锁屏并输入密码解锁
- 支持意见反馈提交
- 支持旧版本本地数据迁移提示与导入流程

## 页面与路由

当前项目的主要页面如下：

| 路由 | 页面说明 |
| --- | --- |
| `/auth` | 登录 / 注册 / 重置密码 |
| `/points` | 积分主页面 |
| `/points/history` | 积分历史记录 |
| `/points/shop` | 积分商城 |
| `/students` | 学生与分组管理 |
| `/tools` | 工具箱首页 |
| `/tools/timer` | 计时器 |
| `/tools/rollcall` | 点名器 |
| `/tools/lottery` | 抽奖器 |
| `/settings` | 设置页 |
| `/opinion` | 意见反馈 |

补充说明：

- 根路径 `/` 会重定向到 `/points`
- 未登录访问业务页时，会自动跳转到 `/auth`
- 已登录状态再次访问 `/auth` 时，会自动跳转到 `/points`
- 积分商城是独立路由 `/points/shop`，不是侧边栏一级主菜单

## 业务规则说明

### 学期规则

- 当前班级的最新学期可正常进行积分操作与商城兑换
- 归档学期下，积分页面不可正常进行积分操作
- 归档学期下，商城页面仅可浏览，不支持兑换奖品
- 切换到新学期后，旧学期数据主要用于查看历史

### 积分规则

- 项目中同时存在“总积分”和“可用积分”
- 商城兑换消耗的是“可用积分”
- 排行榜当前已支持展示，但部分场景下仍存在以前端数据兜底的逻辑

### 锁屏规则

- 锁屏密码保存在本地浏览器
- 锁屏密码经过摘要处理，不以明文存储
- 未设置锁屏密码时，无法直接锁屏

## 导入与导出

项目已实现多种 Excel 导入导出能力，适合教师快速初始化数据。

### 已支持的导入

| 功能 | 模板字段 |
| --- | --- |
| 学生导入 | `姓名`、`性别（可选）` |
| 分组导入 | `分组名称`、`学生姓名` |
| 积分项导入 | `组名`、`项目名`、`分值` |
| 积分导入 | `姓名`、`分值`、`项目（可选）` |
| 商城商品导入 | `商品名称`、`积分`、`库存`、`描述（可选）` |

### 已支持的导出

- 积分结果导出
- 积分历史导出
- 导出时支持按范围筛选

## 交互与体验特性

- 基于 `Element Plus` 实现统一交互风格
- 高频操作集中在页面下方或易触达区域，适配大屏触控

- 页面切换与请求过程提供统一 loading 反馈
- 关键操作包含弹窗确认、成功提示、失败提示

## 环境变量与接口说明

项目请求基础地址默认读取 `VITE_API_BASE_URL`，如果未配置，则默认使用 `/api`。

开发环境下，Vite 已配置代理：

- `/api` 会代理到 `http://localhost:8080`

因此你可以按下面方式配置后端对接：

- 方案一：本地后端直接运行在 `http://localhost:8080`
- 方案二：通过环境变量 `VITE_API_BASE_URL` 指向其他服务地址

## 当前已知限制

以下内容是根据当前代码现状整理出的说明，不是规划功能：

- “清空积分记录”按钮目前仅提示，后端暂不支持真正清空
- 商城记录不能在积分历史页面中直接撤回，需要去商城管理页处理
- 抽奖器中的“删除奖池”当前后端暂不支持
- 排行榜存在部分以前端数据兜底的逻辑，说明后端能力仍在衔接中
- 工具箱中的“更多工具”仍是占位入口
- 仓库中存在历史备份文件，例如 `src/views/AuthView.bak.vue`，当前正式入口仍以现有路由引用文件为准
