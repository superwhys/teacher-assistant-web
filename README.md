## 🎓 教师助手（Teacher Assistant）

面向中小学教学场景的一体化课堂管理工具。支持班级/学生/积分管理与课堂工具，专为教室触控大屏优化，同时在电脑与手机端自适应显示，开箱即用、断网可用、上手极快。

### 🧑‍🏫 适用场景

- **课堂管理**: 🎯 点名抽取、⏱️ 课堂计时、📝 课堂表现记录
- **常规教务**: 🗂️ 班级/学生名册维护、🧩 分组管理、🏅 积分制考核
- **多设备**: 🖥️ 触控大屏主控、💻 电脑管理、📱 手机临场操作

### ⭐ 核心功能

- **🏫 班级管理**
  - 🆕/🔄/🗑️ 班级；底部快捷选择当前班级
  - 🕒 实时显示当前时间与 🗓️ 日期，便于课堂展示

- **👩‍🎓 学生管理**
  - ✍️ 单个添加、🧑‍🤝‍🧑 批量添加、📥 Excel 导入（支持“姓名/性别”）
  - ✏️ 编辑姓名/性别；❌ 删除并自动从所有分组移除

- **🧩 学生分组**
  - ➕/✍️/➖ 分组，所见即所得调整成员
  - 👀 名单筛选支持“全部/指定分组”切换

- **🏅 积分管理（正负分制）**
  - 📦 预置“作业/课堂表现”等积分项，支持自定义
  - ➕/➖ 对单个/多人/全体一键加扣分，实时生效
  - ↩️ 撤回最近一次操作；📄 按学生查看记录

- **🗃️ 积分记录与检索**
  - 🕘 按时间倒序展示所有变动
  - 🔍 按分组/类型/姓名关键词过滤
  - ↩️ 对任意记录“撤回”恢复原积分

- **🧾 Excel 导入 / 导出**
  - 📥 积分项导入：“积分组/项目名/分值（±）”，自动创建缺失分组
  - 📥 积分导入：“姓名/分值（±）/项目”批量写入积分
  - 📤 导出“最终积分/积分历史”，可选“全部/指定分组”

- **🧰 课堂工具箱**
  - ⏱️ 计时器：分钟/秒可调、预设/开始/暂停/重置、进度条大字显示
  - 🎲 点名器：随机抽取；支持“按分组/不重复/历史列表”

- **🔐 设置与安全**
  - 🔑 访问密钥：验证后解锁功能
  - 🔒 锁屏防误触：设置密码，支持立即锁定/解锁
  - 🗄️ 备份与恢复：本地一键导出/导入（JSON）
  - ☁️ 云端同步：一键备份与历史恢复（需后端），自动同步开发中

### 🖥️ 体验与设计

- **👇 触控优化底部操作栏**：高频操作固定底部，贴合大屏触控
- **📱 响应式布局**：4K 大屏到手机全面适配
- **💾 本地持久化**：数据保存在本地，断网可用
- **✅ 即时反馈**：关键操作有提示并支持撤回

### 🛠️ 技术栈

- ⚡ Vue 3 + TypeScript + Vite
- 🧩 Element Plus + Element Plus Icon（自动按需引入）
- 🗃️ Pinia（含持久化）
- 💽 localForage（本地 KV 存储）
